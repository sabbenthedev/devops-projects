# devops-projects

a monorepo tracking practical linux system administration, cloud infrastructure, containerization, and ci/cd projects built and maintained across local and cloud environments.

## system architecture & specs

- **OS server:** Ubuntu Server 26.04.1 LTS
- **workstation / management host:** HP EliteBook 840 G1 (Linux/CLI Client)
- **core tools & stack:** Bash, Git, Systemd, UFW, OpenSSH, Nginx, Docker, Docker Compose, Terraform, Ansible, AWS EC2, DigitalOcean, Prometheus, Grafana
